What each run does

Smoke check (default, read-only)
Loads the page and reports its HTTP status, console errors and failed requests. It does not verify any UI claims.
Truthfulness check
Runs your flows, works out what the UI claimed (deleted, saved, added…), reloads the page, and checks the claim survived. This catches fake deletes and saves that never persist, with no backend access needed.
Repository
Reads the project layout (framework, suggested run commands) without executing anything.
